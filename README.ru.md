# Clipboard Sync

Автоматическая синхронизация буфера обмена между вашим Android-телефоном и
Galaxy Watch (Wear OS) — и между любыми вашими устройствами.

**Языки:** [English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md)

## Возможности

- **Автоматическая синхронизация** — скопировали на одном устройстве, вставили
  на другом. Ничего нажимать не нужно.
- **Два независимых канала одновременно:**
  - **Wi-Fi** — устройства в одной сети находят друг друга автоматически (mDNS);
  - **Bluetooth** — работает между спаренными устройствами даже в *разных* сетях.
- **На часах:** принятый текст показывается полноэкранно поверх блокировки,
  экран включается даже если был выключен, текст листается свайпом или вращением
  bezel, а экран не гаснет, пока сообщение не закрыто.
- Автозапуск после перезагрузки, автоматическое переподключение после сна
  или обрыва связи.
- Интерфейс на **русском, английском и немецком** языках.
- **Без серверов и без доступа в интернет.** Данные идут напрямую только между
  вашими устройствами.

## Требования

| Устройство | ОС |
|---|---|
| Телефон | Android 8.0+ |
| Часы | Wear OS 3+ (Galaxy Watch4 / Watch5 / Watch6 / Watch7 / Watch8 / FE) |

## Установка

1. Скачайте APK со страницы [Releases](../../releases):
   - `ClipboardSync-phone.apk` — для телефона;
   - `ClipboardSync-wear.apk` — для часов (установка через `adb install` или
     через Galaxy Wearable / Wear OS).
2. Запустите приложение на обоих устройствах и включите **переключатель
   синхронизации**.
3. Выдайте запрошенные разрешения (Bluetooth, уведомления).
4. Нажмите **«Настройки доступности»** и включите **Clipboard Sync** в списке —
   Android 10+ не позволяет читать буфер обмена в фоне без этого сервиса.
5. Держите оба устройства в одной Wi-Fi сети и/или спаренными по Bluetooth —
   они найдут друг друга автоматически.

### Советы

- **Xiaomi / MIUI / HyperOS:** включите приложению автозапуск (Настройки →
  Приложения → Разрешения) и нажмите в приложении кнопку
  **«Отключить оптимизацию батареи»** — иначе система будет убивать фоновый сервис.
- **Гостевой Wi-Fi с изоляцией клиентов:** авто-поиск не сработает — добавьте
  устройство вручную по IP в приложении.

## Как это устроено

- Устройства объявляют себя через **mDNS** (`_clipboardsync._tcp`) и обмениваются
  сообщениями в формате **JSON** по TCP (порт 47821).
- **Bluetooth RFCOMM (SPP)** — соединения со всеми спаренными устройствами.
- Подавление эха: каждое сообщение несёт id отправителя и SHA-1 текста,
  поэтому один и тот же текст никогда не применяется в цикле.
- Взаимные одновременные подключения дедуплицируются детерминированно
  (побеждает сокет, инициированный устройством с меньшим id).

## Сборка из исходников

Нужны **JDK 17** и Android SDK (platform 34).

```bash
./gradlew :phone:assembleRelease :wear:assembleRelease
```

APK появятся в `phone/build/outputs/apk/release/` и
`wear/build/outputs/apk/release/`.

Для подписи релизов положите свой keystore в `keystore/release.keystore`
(алиас `clipboardsync`) — без него соберётся неподписанный APK.

## Конфиденциальность

В приложении нет аналитики, трекеров и доступа в интернет. Текст буфера обмена
передаётся только напрямую между вашими устройствами.
